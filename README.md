# 划词小窗搜索

Chrome 浏览器扩展：划词后点击悬浮图标或右键菜单打开小窗搜索，可自定义搜索引擎。

## 版本

`v4.24.0806`

## 更新内容

### 界面优化
- 所有设置页统一为**侧边栏 + 内容区**双栏布局，左侧导航固定
- 改善字体大小、行距、间距一致性，弹窗 padding 统一
- 设置页全局样式现代化（CSS 变量、卡片阴影、表单 focus 光环）

### 搜索引擎模块（常规设置）
- 搜索引擎列表从表格改为**卡片式布局**，每行显示图标预览 + 名称 + URL + 类型标签 + 操作按钮
- 类型标签彩色化（AJAX 蓝 / DOMParser 橙 / iframe 绿 / newtab 紫）
- 操作按钮改为三角形/铅笔图标

### 自定义引擎弹窗
- 类型选择从 radio 改为 **2×2 可视化卡片**（带图标和描述）
- 网址模板下方新增**变量快捷插入按钮**（`${query}`、`${paged}`、`${hostname}`、`${first}`、`${start}`、`%s`）
- 弹窗新增可选设置（悬浮图标 / 右键菜单开关）

### 样式设置页
- 三个 CSS textarea 替换为 **CodeMirror 语法高亮编辑器**
- 按目标区域拆分为三区：图标浮标区 / 搜索小窗区 / AJAX 内部区
- 新增**实时预览面板**（编辑 CSS 即时反映在模拟图标上）
- 新增**图标图片上传**（拖拽/选择图片 → 自动 base64 嵌入 → 生成 CSS 代码）

### 数据管理
- **WebDAV 云端备份**：支持上传/下载设置到坚果云、群晖、Nextcloud 等，预设坚果云地址
- 搜索引擎**去重检测**：添加/编辑时名称或 URL 重复自动阻止
- **追加内置设置去重**：只追加尚不存在的内置引擎
- **恢复默认后悔机制**：保存最近 3 次历史，支持撤销恢复

## 技术栈

- Manifest V3
- Bootstrap 4 + jQuery
- Vue.js 1.0 CSP
- CodeMirror
