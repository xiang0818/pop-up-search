暗黑模式：使用这段代码把小窗改成暗黑色，或者修改颜色值为你想要的颜色。

#hcSearcheModal #hcSearcheModalContent {background:#3e4451;border-color:#3e4451;border-width: 1px 3px;} #hcSearcheModal hcsearche-link {color: #e9ecef !important;} #hcSearcheModal hcsearche-link[data-securrent=true], #hcSearcheModal hcsearche-link:hover {background-color: #000;border-radius: 3px;}

自定义图标样式例子

如果你设置的图标 CSS class 是 google 那么应该这么写：

#hcSearcheIcons hcsearche-icon[data-seclass=google] { font-size: 0; background-image:url('data:....') }

没错，名义上是 class 实际选择器不是，需要像上面这么写。此外，默认没有图标是显示搜索引擎名称第一个字，所以设置图标时需要将字体大小设为0，否则会文字和图标重叠。而且图标通过 background-image 设置，请将 16x16px 图标 base64 编码后填入，不要使用网址，否则可能因为防盗链等原因加载失败。

图标预览 （当前预览不会在前端生效，因为你没有启用自定义代码，启用设置在本页下方）

样式设置 （图标效果会实时预览，但代码需要手动保存）

影响 AJAX 小窗内排版的样式，包括 DOMParser 模式。CSS选择标题使用 .cse-title ，选择描述使用 .cse-desc ，选择缩略图使用 .cse-img ，选择显示链接使用 .cse-url ，选择整条结果条目使用 .cse-item。

.cse-item 拥有 data-cse-hostname （当前条目的域名）和 data-cse-link （完整链接）属性，可用于选择特定结果，用于高亮或屏蔽。比如 .cse-item[data-cse-hostname*=".wikipedia.org"] { background-color: rgba(0,123,255,.15) } 可使所有链接域名为 .wikipedia.org 的条目背景显示为蓝色。

这里填写的样式会插入到访问的网页中，请严格使用指定选择器指定样式。

#hcSearcheIcons hcsearche-icon {border-color: red; background-repeat: repeat;}
