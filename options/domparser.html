常规设置 自定义样式 WebDAV 备份 DOMParser 使用帮助 关于

DOMParser 解析类型会在后台请求页面并使用本页定义的函数处理返回的 HTML，返回与 AJAX 相同的 JSON 格式的结果以供页面展示。具体格式请参考下方内置函数配置以及使用帮助。

自定义函数 JSON

以 JSON 格式编写，如与内置函数配置重名会覆盖后者。需要注意长度，存储限制最长8192字节。

内置函数 JSON

用于解析 Google、Bing、Baidu 搜索结果，仅供参考，并不保证总是有效，当网页元素命名或元素发生变化时，需要修改选择器才能解析。

如果内置函数配置失效，可以复制到它到自定义配置中修改它直至可用。
